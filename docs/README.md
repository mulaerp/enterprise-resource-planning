## 📖 Documentation Standards

### File Organization
- **Root docs/**: Essential user and developer documentation
- **docs/phases/**: Historical phase completion records
- **docs/archive/**: Obsolete or superseded documents
- **.kiro/steering/**: Project guidelines and current status

### Naming Convention
- `UPPERCASE.md` - Main documentation files
- `PHASE_N_COMPLETE.md` - Phase completion records
- `lowercase.md` - Steering documents

### Update Policy
- Update feature-status.md when features change
- Update roadmap.md when priorities change
- Archive documents when superseded
- Delete documents when obsolete
